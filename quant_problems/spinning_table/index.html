Four Coins on a Spinning Table

Four coins sit at the corners of a square on a round table, each heads or tails at random. You can't see them. Each turn you say which coins to flip, by where they sit in front of you. If all four then match, all heads or all tails, you win. If not, the table turns to an angle you don't know and you go again. What can you say to be sure of winning?

Three shapes

Turning the table, or swapping heads for tails, doesn't change a shape.

Since the table turns and either all-heads or all-tails wins, only the pattern matters. A table that hasn't won has one of three shapes, and a move has one of three kinds: two opposite coins (D), two neighbours (A) or one coin (S). Flipping three is the same as flipping one and then swapping heads and tails, and flipping all four changes nothing.

Read down the D and A columns. D never changes a shape except to win from Diagonal. A swaps Adjacent and Diagonal, or wins from Adjacent. Neither ever touches One.

Why seven

Follow what could still be on the table.

D A D wins any 2–2 table. If the table is Diagonal, the first D wins. If it is Adjacent, D leaves it Adjacent; A then wins or makes it Diagonal; the second D wins Diagonal. One is untouched throughout.

S turns One into a 2–2 table. If D A D hasn't won, the table must be One. Flipping one coin either wins (it was the odd coin) or makes a 2–2 table. Another D A D then finishes it. That is 3 + 1 + 3 = 7 moves.

No six-move plan works. A breadth-first search over everything you could know, trying all 15 ways to choose coins each turn, finds nothing shorter than seven moves. Among plans built from D, A and S, D A D S D A D is the only seven-move plan that always wins.

Every case

All 16 starting tables against all 47 ways the table can turn.

Each count from 0 to 7 is exactly one game in eight, so a random table takes 3.5 moves on average, and no table and no run of turns ever takes more than seven.
