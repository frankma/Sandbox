Heat-Equation Finite Difference

A rod on \(0 < x < 1\) starts with the parabolic profile \(V(x,0) = x - x^2\), its ends are held at zero, and it diffuses at a rate that wobbles in time:

$$\frac{\partial V}{\partial t} = \bigl(0.16 + 0.08\sin t\bigr)\,\frac{\partial^2 V}{\partial x^2}, \qquad V(0,t) = V(1,t) = 0.$$

The task is to estimate \(V(0.5,\,1)\) with centred differences in space and the trapezoid rule in time, show how the estimate converges as the grid is refined, and explain how the code was checked.

The scheme

Replace \(\partial^2 V / \partial x^2\) at each interior node by the centred difference \((V_{i-1} - 2V_i + V_{i+1})/\Delta x^2\). That turns the PDE into a system of ODEs, \(\dot V = a(t)\,D V\).

The trapezoid rule averages the right-hand side over the start and end of each step. The coefficient must be evaluated at both ends too, at \(a(t_n)\) on the known side and \(a(t_{n+1})\) on the unknown side:

$$\Bigl(I - \tfrac{\Delta t}{2}\,a_{n+1} D\Bigr)V^{n+1} = \Bigl(I + \tfrac{\Delta t}{2}\,a_{n} D\Bigr)V^{n}$$

Every step is one tridiagonal solve, so it costs time proportional to the number of nodes. The method is unconditionally stable and second-order in both \(\Delta x\) and \(\Delta t\).

The whole field

The same solution over all of \(0 \le t \le 1\), computed on the Δx = 0.025 grid. The peak at \(x = 0.5\) decays from 0.25 to about 0.037. The decay speeds up slightly towards \(t = 1\), where \(a(t)\) is largest.

Exact solution and checks

The coefficient depends on \(t\) only, so separation of variables still works if time is measured in accumulated diffusivity \(A(t) = \int_0^t a = 0.16\,t + 0.08\,(1 - \cos t)\):

$$V(x,t) = \sum_{k\ \text{odd}} \frac{8}{(k\pi)^3}\,\sin(k\pi x)\,e^{-k^2\pi^2 A(t)}.$$

The numbers on this page are computed live in your browser by a port of solver.py. The unit tests in test/test_solver.py cover:

  • Linear algebraThe Thomas solver returns \([1, 1, 1]\) for the hand-solvable system \(\operatorname{tridiag}(-1, 2, -1)\,x = [1, 0, 1]\).
  • SeriesAt \(t = 0\) the Fourier series reproduces \(x - x^2\) to seven decimals.
  • Boundaries\(V(0,t)\) and \(V(1,t)\) stay exactly zero.
  • SymmetryThe data are symmetric about \(x = 0.5\), and so is the solution, to machine precision.
  • AccuracyThe finest grid is within \(10^{-5}\) of the exact value.
  • OrderEach refinement cuts the error by \(4 \pm 0.1\).
  • Max principleThe peak \(V(0.5, t)\) decreases at every time step.
